# 06. 테스트 및 인수 기준

## 1. 테스트 환경
- 최신 안정 버전의 Chrome 또는 Edge
- 모바일 크기 뷰포트와 데스크톱 뷰포트
- 테스트용 OpenAI API 키와 Supabase 프로젝트
- 실제 비밀 키가 저장소에 커밋되지 않았는지 확인

## 2. 기능 테스트

### 일기 입력·교정
| ID | 테스트 | 기대 결과 |
|---|---|---|
| D-01 | 빈 입력으로 교정 클릭 | 요청하지 않고 입력 안내 표시 |
| D-02 | 공백만 입력 | 요청하지 않고 입력 안내 표시 |
| D-03 | 5,000자 입력 | 제출 가능 |
| D-04 | 5,001자 입력 | 추가 입력 또는 제출 차단, 길이 안내 |
| D-05 | 정상 영어 일기 제출 | 로딩 후 교정 결과 표시 |
| D-06 | 문법 오류가 있는 문장 제출 | 의미를 유지한 교정문과 수정 설명 표시 |
| D-07 | 이미 자연스러운 문장 제출 | 불필요한 수정 최소화 |
| D-08 | AI API 오류 상황 | 친절한 오류 안내, 입력 내용 유지 |
| D-09 | 연속 클릭 | 중복 요청 방지 |
| D-10 | AI 응답 필드 누락 | 안전한 오류 처리, 원시 응답 미노출 |

### 피드백
| ID | 테스트 | 기대 결과 |
|---|---|---|
| F-01 | 빈 피드백 제출 | 저장하지 않고 안내 표시 |
| F-02 | 1,000자 피드백 제출 | 정상 저장 |
| F-03 | 1,001자 피드백 제출 | 저장 거부 및 길이 안내 |
| F-04 | 로그인하지 않고 제출 | 정상 저장 |
| F-05 | 저장 성공 | 성공 메시지와 입력란 초기화 |
| F-06 | 저장 실패 | 입력 내용 유지 및 재시도 안내 |
| F-07 | 페이지 새로고침 | 저장된 피드백 목록 표시 |
| F-08 | 여러 피드백 등록 | 최신 항목이 맨 위에 표시 |
| F-09 | 피드백이 없는 DB | 빈 상태 안내 표시 |
| F-10 | 목록 조회 실패 | 재시도 가능한 오류 표시 |
| F-11 | HTML 태그 형태의 피드백 등록 | 실행되지 않고 텍스트로 표시 |
| F-12 | 연속 제출 클릭 | 중복 저장 방지 |

## 3. 보안 테스트
- [ ] 브라우저 소스·Network 응답·정적 파일에 OpenAI API 키가 없다.
- [ ] `SUPABASE_SERVICE_ROLE_KEY`가 클라이언트에 노출되지 않는다.
- [ ] 일기 원문이 DB에 저장되지 않는다.
- [ ] 일기 원문이 서버 로그에 기록되지 않는다.
- [ ] 피드백 XSS 입력이 실행되지 않는다.
- [ ] 서버에서 길이·자료형 검증을 수행한다.
- [ ] API 요청 제한이 적용된다.
- [ ] 오류 응답에 스택 트레이스·비밀 키가 포함되지 않는다.

## 4. UI 및 접근성 테스트
- [ ] 모바일 폭 360px에서 가로 스크롤이 없다.
- [ ] 데스크톱에서 본문이 과도하게 넓어지지 않는다.
- [ ] textarea와 버튼을 키보드로 조작할 수 있다.
- [ ] 포커스 표시가 보인다.
- [ ] 오류·성공·로딩 상태가 텍스트로 전달된다.
- [ ] 긴 피드백과 영어 문장이 레이아웃을 깨뜨리지 않는다.

## 5. 배포 검증
- [ ] Vercel 환경 변수 4개를 올바르게 설정했다.
- [ ] Build Command는 실제 프로젝트에 존재하는 명령과 일치한다.
- [ ] 정적 페이지가 정상 배포된다.
- [ ] `/api/correct-diary`가 배포 환경에서 응답한다.
- [ ] `/api/feedback` 저장 및 `/api/feedback` GET 조회가 정상 동작한다.
- [ ] 배포된 도메인에서 브라우저 콘솔 오류가 없다.
- [ ] Supabase에 테스트 피드백이 실제로 저장되는지 확인했다.

## 6. 인수 조건
다음 항목을 모두 만족해야 1차 완료로 판단한다.
1. 로그인 없이 영어 일기 교정 요청이 가능하다.
2. 교정문, 수정 설명, 영어 칭찬 문구가 구분되어 표시된다.
3. 피드백이 Supabase에 저장되고 페이지 하단에 최신순으로 나타난다.
4. 사용자 입력 오류와 서버 오류가 구분되어 안내된다.
5. 보안 테스트의 키 노출·XSS 항목을 통과한다.
6. 모바일과 데스크톱에서 핵심 흐름이 동작한다.
7. 테스트 결과와 배포 환경 설정이 문서화되어 있다.
